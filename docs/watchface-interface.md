# 表盘文件接口

包名：`com.yzf.daymatter`。接口由快应用维护，表盘只读；不需要读取内部事件/背景索引。

## 主事件

- 快应用：`internal://files/date.txt`
- 设备路径：`/data/quickapp/files/com.yzf.daymatter/date.txt`
- UTF-8内容：`名称,YYYY-MM-DD,true/false`，最后一项表示计入起始日。
- 无主事件时为空或文件不存在。名称中逗号、换行、制表符替换为空格。
- 年度事件导出本次/下次公历发生日；应用保存、页面进入及前台跨午夜时更新。退出期间不能保证年度日期滚动。

## 自定义背景

- 快应用：`internal://files/background.txt`
- 设备路径：`/data/quickapp/files/com.yzf.daymatter/background.txt`
- UTF-8内容：当前图片的文件名，例如 `bg_1790000000000.png`，不含URI前缀或绝对路径；由表盘自行拼接设备上的应用文件目录。
- 空内容或文件不存在表示默认黑色；不要扫描旧图片作为回退。
- 插件输出PNG无损编码，设备原尺寸、单边≤512px、文件≤256KiB。历史背景仍可能是JPEG。
- 背景加载/迁移、成功上传、恢复默认时维护；先写临时文件再发布，固件不支持覆盖时直接写入回退。
- 接口是可重建的派生文件，写入失败不撤销已保存背景，下次背景加载补写。异步导出最终追随最新引用。
- 表盘建议在创建/亮屏时检查引用，路径变化才重新加载；缺失、空值、读取或解码失败回退黑色。旧图片会在提交后清理，读取失败应稍后重试接口。

当前改动仅提供快应用接口，未修改表盘Lua源码。
